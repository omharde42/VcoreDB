# API Architecture (Planned)

Phase 1 focuses on database foundations only. No runtime API is implemented yet.

Target API/backend module boundaries:
- `/core`
- `/database`
- `/models`
- `/schemas`
- `/services`
- `/repositories`
- `/api`
- `/auth`
- `/middleware`
- `/utils`
- `/migrations`
- `/tests`

Implementation starts in later phases after identity, project, and authorization models are finalized.
